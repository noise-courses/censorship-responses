# Censorship Course — Reading Responses

Template repo for weekly reading responses in the Internet Censorship
and Online Speech course.

## For students — setup (one time, ~2 minutes)

1. Click **"Use this template"** at the top of this page → **"Create a
   new repository"**.
2. **Owner:** your GitHub account. **Name:** anything (e.g.
   `censorship-responses`). **Visibility:** **Private**.
3. In your new repo → **Settings → Collaborators** → **Add people** →
   `feamster` → **Read** permission → send invitation.
4. Fill out the intake form (link in the syllabus / Slack): tells me
   your first name, last name, GitHub username, and which course.

**Do not submit anything to Canvas.** All reading responses come in
through the private repo you just created.

## Weekly workflow

Each week, before the reading is discussed:

1. Create a new file `week-NN.md` (e.g. `week-01.md`, `week-02.md`).
2. Fill in the response format below.
3. Commit and push.

I pull your repo before class and use your questions to drive
discussion.

### Deadlines

- **Week 1 (this week):** submit by **Friday**.
- **Weeks 2 and 3:** submit by **Monday, 9am**.
- **No penalty for submitting early.** The sooner it's in, the more I
  can do with it.
- We meet three times per week but responses are **once per week** —
  respond to whichever chapter of the week grabs you (we cover roughly
  2 chapters per week: chapters ~6, ~12, ~18 by the end of weeks 1, 2, 3).

## Response format

Each `week-NN.md` should contain the following. Copy the template into
your file and fill it in:

```markdown
## Reading Response

**Questions**
What questions do you have after reading? (1–2 sentences is plenty.)

*If you used AI tools (Claude, ChatGPT, etc.) to help you think about
this reading, please acknowledge them briefly here.*
```

### Why so short?

I intentionally kept it to 1–2 sentences. Longer prompts nudge people
toward token-generator answers, which help nobody. Just tell me what
you actually wondered about.

### What about the summary?

Previous versions of this template asked for a short summary of the
reading too. **Not anymore.** Skip the summary — go straight to your
questions.

## What counts

- Weekly responses are graded for **completion**, not correctness.
- Late responses eat into the grace-period balance in the
  [course syllabus](https://noise-lab.github.io/censorship-course/syllabus).
- I pull your repo automatically before each class meeting — no
  separate submission step after your one-time setup above.
